# Problem Statement & Project Scope

## Project Title
MY-PYTHON-CHATBOT-PROJECT: Rule-Based Terminal Chatbot

---

## Problem Statement
In modern introductory computing, users often require lightweight, accessible tools for quick daily queries without relying on heavy external software or persistent internet connectivity. This project addresses the need for a standalone, terminal-based conversational agent capable of handling everyday user prompts, performing basic arithmetic, and providing system utility functions efficiently using core Python logic.

---

## Objectives
- **Interactive CLI Interface:** Build a responsive command-line interaction loop that continuously processes user input.
- **Intent Recognition:** Implement rule-based conditional logic and keyword mapping to accurately route user queries.
- **Built-in Utility Functions:** Integrate real-time system time/date reporting and automated arithmetic evaluation.
- **Fault Tolerance:** Ensure robust error handling for unexpected inputs or mathematical errors (e.g., division by zero) to prevent execution crashes.

---

## Target Audience
- First-year computer science students and academic evaluators.
- Users seeking a lightweight, terminal-native assistant for simple calculations and quick info retrieval.

---

## Technical Scope
- **Language:** Python 3.x
- **Standard Libraries:** `datetime`, `time`
- **Architecture:** Procedural/rule-based execution loop utilizing conditional statements and pattern matching.
