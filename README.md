# MY-PYTHON-CHATBOT-PROJECT

A simple terminal-based chatbot created for a first-year Python programming assignment.

## Overview
This chatbot processes general user prompts using conditional logic and keyword matching. It handles basic greetings, jokes, current date/time queries, and solves arithmetic math problems directly from user input.

## Features
- **General Chat:** Responds to greetings, inquiries, jokes, and help requests.
- **Time & Date:** Displays real-time system timestamps using Python's `datetime` module.
- **Math Calculation:** Solves single-operation math problems (+, -, *, /) with or without spaces (e.g., `calc 10 + 5` or `what is 45*2`).
- **Session Tracking:** Displays total valid queries upon exit.
- **Error Handling:** Handles division by zero and invalid input gracefully without crashing.

## Tech Stack
- **Language:** Python 3.x
- **Modules Used:** `datetime`, `time`

## How to Run

1. Clone or download `pybot.py` from this repository.
2. Open **Command Prompt** or **Terminal** on your computer.
3. Navigate to the folder where `pybot.py` is located, or specify its file path.
4. Execute the script using Python:

   ```bash
    pybot.py
